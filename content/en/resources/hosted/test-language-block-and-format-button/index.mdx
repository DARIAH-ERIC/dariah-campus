#### Making use of the 'Languages' formatting option

This is perhaps also a good opportunity to let you know that you can write in different languages using different writing systems using the 'Language' option in the formatting bar above.  This allows you to add text in a different writing system or alphabet, and ensures that it is formatted correctly according to that language.  For example, this text in Urdu below:

<Language lang="ur">یہ اردو زبان کی تربیتی وسائل میں استعمال ہونے کی ایک مثال ہے۔</Language>

<LanguageBlock lang="ur">
  یہ اردو زبان کی تربیتی وسائل میں استعمال ہونے کی ایک مثال ہے۔
</LanguageBlock>
