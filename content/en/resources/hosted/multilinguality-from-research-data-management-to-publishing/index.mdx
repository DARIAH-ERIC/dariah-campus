## Learning outcomes

After completing this training resource, learners should be able to:

* Know the strategies, tools, and standards to manage multilingual research data
* Plan multilingual research data in order to improve findability and visibility of language diversity
* Publish and disseminate multilingual research

This module is accompanied by examples, reflexive activities and concrete use cases related to multilingual projects.



## 1. Know the Strategies, Tools and Standards to manage Multilingual Research Data

**Introductory context**

A research dataset typically contains data about entities and/or relations between entities. If your goal is to make your research dataset readable in several languages, you do not need to translate the names of the entities you describe to other languages. You would rather choose to describe these entities using a Uniform Resource Identifier (URI), which enables you to retrieve multilingual labels (and more), and use these as entity descriptor, instead of literal values (names). If you start from an existing dataset containing literal values instead of identifiers, you can use tools like [OpenRefine](https://marketplace.sshopencloud.eu/tool-or-service/hpBfcf) for finding the URI you need.

In the following, we give main recommendations for which sources for web identifiers to choose, together with examples. Clicking on the URI, you get to lists of multilingual entity labels (and more information). If you use a Linked Data database software, you can import all these labels (together with any other information found in these sources) into your own database environment.

### 1.1 Open Source Wikimedia tools and platforms for multilingual purposes 

[Wikimedia tools](https://en.wikipedia.org/wiki/Wikimedia_movement#Content_projects) are interoperable and multilingual from the start, enabling the integration of researchers' content and data in the semantic web to expand research impact beyond Academia.

[MediaWiki](https://www.mediawiki.org/wiki/MediaWiki) is a multilingual documentation platform with advanced collaborative features that is used by Wikipedia and the other Wikimedia tools.

Wikibase is a set of MediaWiki extensions that enables the use of semantically organized data. This suite supports the [Wikidata](http://wikidata.org/) platform.&#x20;

It can also be used by researchers with no maintenance costs in a [cloud service](https://www.wikibase.cloud/). Researchers may create Wikibase.cloud service instances to host their own documentation and data and connect it to Wikidata, functioning as an indexer hub, enabling federated queries with organizations like GLAM (Galleries, Libraries, Archives and Museums) institutions ([GLAM cultural heritage](https://en.wikipedia.org/wiki/GLAM_\(cultural_heritage\))).
