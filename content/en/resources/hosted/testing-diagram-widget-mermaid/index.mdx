You can use Mermaid to create a diagram from a code block.

<Diagram link={false}>
  <DiagramCodeBlock>
    ```mermaid
    flowchart TD
        cookie_monster["Cookie Monster"] -->|wants| biscuits
        biscuits -->|on Monday| chocolate_chip["chocolate chip"]
        biscuits -->|on Tuesday| custard_cream["custard cream"]
        biscuits -->|on Friday| gingerbread
    ```
  </DiagramCodeBlock>

  <DiagramCaption>
    On the cookie monster's biscuit preferences.
  </DiagramCaption>
</Diagram>

To create a flowchart diagram, you need to insert a code block in the **diagram widget**. When using mermaid, you need to provide mermaid as a language tag (i.e. \`\`\`mermaid). The language is displayed in a little popup window. Below, you can see what the code block for the flowchart on the cookie monster's preferences looks like.

<Figure src="/assets/content/assets/en/resources/hosted/testing-diagram-widget-mermaid/screenshot-mermaid-cookie-monster.png" alt="A code block that shows the code for the cookie monster's preferences flowchart" alignment="stretch">
  Flow chart code block
</Figure>



<Callout kind="note">
  The information on language tag and mermaid documentation appears automatically and is not displayed as part of your code block.
</Callout>



Mermaid allows to visualise your information in various kinds of diagrams. For example, instead of a flow chart, you can create a graph like the one on below on Shakespeare's authorship.

<Diagram link={false}>
  <DiagramCodeBlock>
    ```mermaid
    graph LR
        accTitle: Shakespeare is author of Hamlet.
        accDescr: A diagram showing that Shakespeare is the author of Hamlet.
        shakespeare["Shakespeare"] -->|is author of| hamlet["Hamlet"]
    ```
  </DiagramCodeBlock>

  <DiagramCaption>
    This diagram describes that Shakespeare is the author of the play Hamlet. The diagram describes the relationship of the entities Shakespeare and Hamlet.
  </DiagramCaption>
</Diagram>

Your code block will look similar to the flow chart code block above.

<Figure src="/assets/content/assets/en/resources/hosted/testing-diagram-widget-mermaid/screenshot-mermaid-shakespeare-graph.png" alt="The code block shows the use of mermaid for creating a graph." alignment="stretch">
  Graph code block
</Figure>



<Callout kind="note">
  You need to indicate what kind of diagram you want to display and add code appropriately.
</Callout>

For more information and example uses of mermaid, you can follow the link in the diagram widget.
