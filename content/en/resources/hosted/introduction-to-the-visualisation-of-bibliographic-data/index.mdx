## Introduction

This chapter explains the possibilities of a number of widely used tools that can be used to analyse and to visualise a bibliographic data set. The various methods will be illustrated using a data set exported from the Incunabula Short Title Catalogue (ISTC). The export, more specifically, contains all the titles published between 1450 and 1501 in Great Britain. The export was made in the MARC format. It has been converted to CSV using the MARCReader library. This chapter demands a basic proficiency in Python. 

## Learning Outcomes



* Learn the various possibilities to analyse and visualise a bibliographic data set;
* Using pandas in Python to examine bibliographic data;
* Visualising bibliographic data using Plotly in Python; 
* Learn the basics of network analysis;
* Apply Networkx in Python and Gephi to visualise bibliographic data as a network; 
* Create a map with Folium in Python; 
* Learn how visualisations can help you to examine and understand your data.
